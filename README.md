The day's stories were chosen from its most widely reported events across regions and fields, checked against several news outlets of the day. The picture was composed as a flat editorial poster drawn in vector panels, with the date set large so it stays legible at small sizes.

The finished file, entry.png, is a 1024x1024 PNG of 160,087 bytes (about 160 KB), well under the 1 MiB cap. main.ts simply copies that image to the output directory, deterministically, then verifies the written file's size and PNG signature.
